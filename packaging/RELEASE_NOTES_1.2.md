# TPS AI Trading Assistant — Release 1.2

Release date: 12-08-2026

## Highlights

- Added Windows desktop notifications with global, sound and event-wise controls.
- Added support/resistance proximity and level-cross alerts from live Market Snapshot levels.
- Added the Put-Call Ratio & OI Observer with Call/Put OI, Change in OI, OI-PCR, Volume-PCR, OI walls and explainable sentiment.
- Added Pre-Candle Probability Lab and TPS Powerful Engine with walk-forward purity validation and safe WAIT behaviour.
- Added official read-only Dhan and Paytm Money broker adapters alongside Angel One.
- Added permanent post-market TPS analysis, CAS Analysis, Stock Options Watch, Option Strategies and India VIX context.
- Protected user settings across source updates, fresh builds and installer upgrades using AppData migration, atomic writes and backup recovery.

## Upgrade behaviour

Installing Release 1.2 over an older release does not overwrite the user's saved trading setup, theme, notification choices or securely stored broker credentials.

## Safety

TPS remains a read-only analysis and paper-trading assistant. It does not place, modify or cancel broker orders and does not guarantee returns. OI sentiment and probability readings require chart, volume, liquidity, risk and news confirmation.
